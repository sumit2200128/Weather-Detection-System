# 🌤️ Weather App

A sleek, responsive, and real-time Web Weather Application designed to provide accurate weather information, search functionality, and visual atmospheric condition indicators.

---

## 📌 Features

- **Real-Time Weather Data:** Displays current temperature, humidity, wind speed, and general atmospheric conditions for searched locations.
- **Location Search:** Easily search for weather conditions across different cities globally.
- **Dynamic Visuals & Assets:** Includes custom weather icons and atmospheric background images (rain, humidity, wind, etc.) to enhance the user interface experience.
- **Responsive Design:** Fully optimized with custom CSS for desktops, tablets, and mobile devices.
- **Clean UI/UX:** Built with intuitive layout structures for seamless user interactions.

---

## 🛠️ Tech Stack & Technologies Used

- **HTML5:** Semantic structure and content markup (`weatherr.html`).
- **CSS3:** Custom styling, responsive design layouts, and UI enhancements (`style.css`).
- **JavaScript (ES6+):** Dynamic DOM manipulation and weather data handling (`scripts.js`).
- **Asset Collection:** Custom UI icons and background imagery for visual status indications.
